# Avon Data Analysis Project

## Project Overview

This project analyses Avon sales data using Microsoft Excel. The purpose of the analysis was to clean, organise, and analyse the dataset to identify useful patterns and insights from the data.

## Objectives

- Clean and organise the raw dataset
- Analyse sales data using Excel
- Identify trends and patterns
- Create summaries and visualisations
- Present findings through an interactive dashboard

## Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Organisation
- Pivot Tables
- Excel Formulas
- Data Analysis
- Data Visualisation
- Dashboard Design

## Data Cleaning

The dataset was cleaned and prepared for analysis by:
- Removing duplicate records
- Checking for missing or inconsistent values
- Standardising data where necessary
- Organising the dataset into a structured format

## Analysis

The analysis focused on areas such as:
- Sales performance
- Product performance
- Customer information
- Trends and patterns within the dataset

## Dashboard

The final dashboard presents key findings from the analysis using charts, tables, and summary metrics.

## Files

- `Avon Project.xlsx` – Excel workbook containing the cleaned data, analysis, and dashboard.
